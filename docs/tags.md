# Wiki tags

Every page starts with YAML frontmatter: a `tags` list drawn only from this page,
and a one-line `summary`. Search by tag instead of reading every page. In
Obsidian the tag pane lists them; elsewhere, search for `tags:` lines.

```yaml
---
tags: [workflows, comfy, ltx]
summary: One line that says what the page holds.
---
```

Put the page's area first, then the topics it covers in depth, not every topic
it mentions. Add a tag here, in the same change, before using it on a page.
