# Teaser claim rules

Part of [the teaser run kit](README.md). A run may only put words on screen
that are true about what the studio did. The verifier
(`scripts/verify-teaser-run.mjs`) enforces it: a string is **approved** when the
v1 or v2 cut or the cut bundled on `main` already carries it (the owner
merged those words), and anything else fails until the owner says yes.

## Never write

Each rule is a correction the owner made, or the reason behind one. New
wording that matches any of these fails even with `--allow-new-wording`.

| Rule            | Matches                                                                               | Why                                                                                                                                         |
| --------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| unrelated-tool  | An unrelated tool's name                                                              | The creature clips are the owner's MiniMax H3 outputs; do not attribute them to another tool.                                               |
| open-claim      | "open weights", "open source", "local and open", "open model"                         | Cut 1 said "open weights" over a FLUX 3 shot. The clips came from closed models too.                                                        |
| provenance      | "made / generated / created / rendered / shot / produced with / by / on / in / using" | Say what the studio did (CUT IN GENOBI), never where a clip was made. The end card's "MADE WITH" + "GENOBI" is approved because it is true. |
| provider        | MiniMax, Kling, Runway, Sora, Veo, Midjourney, Pika, Luma, Seedance, Hailuo           | No provider over a clip. Model names appear only in the approved callout and over the forest guardian (a FLUX 3 run).                       |
| invented-result | "Draft ready", "rendered in 3 s", "ready … 10 s"                                      | Cut 1 said "Draft ready · 20 s on the beat" for a draft nobody made, and "Shot ready · 10 s".                                               |
| superlative     | best, fastest, first ever, only studio, #1, world's, revolutionary, guaranteed        | Nobody can check it.                                                                                                                        |

## Checklist before you write a word

1. Is the string in the approved table? Copy it exactly and stop here.
2. If not: does it describe something the studio visibly does in this shot
   (a button pressed, a box shown, a loader running)? If not, do not write it.
3. Does it name a model? Only "FLUX 3", only over the forest guardian
   (`character`) or the reveal card, and only as the approved wording does.
4. Does it name a provider, claim "open", say where a clip was made, give a
   duration or a result nobody produced, or boast? Then do not write it.
5. New wording needs the owner's yes. Record the yes in `memory.json`
   (`corrections`, quoting the owner), then run the verifier with
   `--allow-new-wording`.
