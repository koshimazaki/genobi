# Generate your version

Open an editable template in Director or Editor. **Generate my version** opens
with it; reopen the panel from either workspace's header. Closing the panel
keeps the project. Switching between Director and Editor uses the same document.

**Make it yours** shows the template’s actual media in a compact grid above the
editable description. Preview an asset larger, drop a replacement onto its slot,
or select another project asset. Replacements commit to this project with Undo;
the Generate button below reads those same assets and the saved description.
Character, style, font and other reference bindings remain in the saved brief.
In the generation panel, **Advanced · description and references** opens the
optional brief after the media cards. It starts collapsed; closing the disclosure
keeps the text and bindings intact.
Finished mixes show their declared template direction, which you can edit; this
is not a claim to know the example footage’s original generation prompt.

The shared landscape panel derives its inputs from the template: character/reference images,
audio, cut footage and pictures inside graphics. Existing replacements and title
edits appear as the current inputs. Choose project Assets or Inspirations, upload
files by dropping them on the large media boxes, or keep the defaults. Audio can be previewed and picked from owned Camera
results. Required kinds, counts and duration checks preserve the current cut.
Removing a reference also removes its saved brief token in the same undoable
edit, so reducing the reference count cannot leave a handoff with an unbound
image token. Unrelated references and the person's description stay intact.

**Apply swaps only** commits a local edit with Undo. It does not generate or start
an agent. A graphic's picture may change while its text and animation remain
editable; its image bytes travel in the saved project ZIP.
The plan review also offers **Apply swaps and continue editing**, including on the
hosted studio. A finished mix with every input set to reuse has no agent step:
the action applies the current media and Words and closes the panel. House
templates with shots to generate retain their agent preparation path.

For finished mixes, unchanged example video slots initially request replacements;
your uploaded or generated clips initially stay in place. Review these choices.
Select **Generate replacement with my agent** for each replacement you want made.
Existing media stays in place while a replacement is planned. **Review generation
plan** lists the current Words, media choices and declared shots. Words edits
update generated subject and title lines in the description; custom prose is
preserved. The handoff names the current Words explicitly, including when an
older saved description still contains template defaults. **Prepare with Genobi** applies the
inputs and sends the current project, complete saved Make it yours brief and
reference bindings, direction and edits to the agent workflow.
If an agent is not configured, the existing setup flow guides you through it.

Every Director generation handoff uses the linked agent. The panel itself never
quotes or submits a generation batch. The agent reads actual files and current
project state, asks for missing creative direction, prepares models/workflows,
and shows quotes and the total. Paid steps wait for explicit approval in the
Genobi bubble. Failed or uncertain submissions are never retried automatically.
Results return through the shared project commands with revision checks, keeping
clip timing, graphics and the person's other edits.

Finished mixes support both local swaps and agent-requested replacement media.
Their example footage is not a record of an exact original generation prompt;
the agent must not infer one from the video.

## Hosted editing

The hosted studio can apply swaps and save an editable ZIP. Its paired runner
does not synchronize project files. To generate from this project, save the ZIP,
open the local studio and import it there. The hosted panel offers these actions
and withholds agent submission while no local project copy is available.
**Open local studio** opens the same template in Director or Editor, with the
generation panel and requested replacement slots. Uploaded media, custom
descriptions and timeline edits travel in the explicit project ZIP; a link or
account pairing does not transfer them or approve generation.
