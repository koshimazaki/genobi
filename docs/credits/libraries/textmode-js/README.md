# textmode.js

**Created by [humanbydefinition and contributors](https://github.com/humanbydefinition).**

WebGL2 character-grid drawing, compositing and image/video-to-glyph conversion.

## Genobi relationship

Optional ASCII/textmode: media treatments, live visuals and interactive website/game experiments. Requires WebGL2; preview and export performance must be measured. Not installed. Selected from [Uncommon Web / Teknium](https://webdev.teknium.io/).
This is an opt-in resource for a matching brief, not a default style or a full game engine.
No runtime, demo assets or source implementation have been copied into Genobi.
