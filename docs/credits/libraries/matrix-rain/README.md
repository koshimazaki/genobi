# Matrix digital rain

**Created by [Rezmason and contributors](https://github.com/Rezmason).**

GPU code-rain effect with URL-configurable variants and palettes.

## Genobi relationship

Optional glyph effect: backgrounds, terminal atmospheres and video layers. Teknium showcases seven variants; upstream has more. WebGL/REGL renderer, with experimental WebGPU support; not installed. Selected from [Uncommon Web / Teknium](https://webdev.teknium.io/).
This is an opt-in resource for a matching brief, not a default style or a full game engine.
No runtime, demo assets or source implementation have been copied into Genobi.
