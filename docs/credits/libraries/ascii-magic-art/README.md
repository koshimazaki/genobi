# ascii-magic-art

**Created by [ASCII Magic / kailashsr38 and contributors](https://github.com/kailashsr38).**

Animated ASCII pieces, glyph looks and text/canvas players; upstream lists 634 pieces.

## Genobi relationship

Optional ASCII/textmode: selected loaders, scenes, backgrounds and website illustrations. Consider canvas frames for video overlays; not integrated or render-tested here. Selected from [Uncommon Web / Teknium](https://webdev.teknium.io/).
This is an opt-in resource for a matching brief, not a default style or a full game engine.
No runtime, demo assets or source implementation have been copied into Genobi.
