# play.core

**Created by [Andreas Gysin / ertdfgcvb and contributors](https://github.com/ertdfgcvb).**

ASCII playground runtime for programs returning a character for each cell.

## Genobi relationship

Optional textmode: generative glyph sketches, website toys and experimental game visuals. Adapt the DOM/text output to a verified capture path before video use; not installed. Selected from [Uncommon Web / Teknium](https://webdev.teknium.io/).
This is an opt-in resource for a matching brief, not a default style or a full game engine.
No runtime, demo assets or source implementation have been copied into Genobi.
