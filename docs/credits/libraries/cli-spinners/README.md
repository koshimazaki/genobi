# cli-spinners

**Created by [Sindre Sorhus and contributors](https://github.com/sindresorhus).**

Frame-and-interval JSON for terminal loading animations; 90 definitions in the reviewed snapshot.

## Genobi relationship

Optional text/glyph animation: aesthetic and binary are useful starting points for loaders and video overlays. Both specify 80 ms per frame. Use an explicit render clock for repeatable video; not installed. Selected from [Uncommon Web / Teknium](https://webdev.teknium.io/).
This is an opt-in resource for a matching brief, not a default style or a full game engine.
No runtime, demo assets or source implementation have been copied into Genobi.
