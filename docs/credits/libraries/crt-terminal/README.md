# crt-terminal

**Created by [Dmitriy Lipin](https://github.com/essserrr).**

React terminal shell with queued text, loaders and CRT styling.

## Genobi relationship

Optional textmode: terminal scenes, website shells or phosphor overlays in videos; reference only, not installed. Verify React peer compatibility before adoption. Selected from [Uncommon Web / Teknium](https://webdev.teknium.io/).
This is an opt-in resource for a matching brief, not a default style or a full game engine.
No runtime, demo assets or source implementation have been copied into Genobi.

A concrete treatment: simulate a cyberpunk terminal inside a video and layer a
`cli-spinners` loader over its screen. This is a composition recipe to explore,
not an existing Genobi effect. Keep the terminal content, glyphs and timing editable.
